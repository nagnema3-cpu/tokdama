# 톡톡 다마고치

가족이 함께 키우는 다마고치 웹앱이에요. 휴대폰·태블릿에서 주소를 열고 "홈 화면에 추가"를 누르면 앱처럼 써요.

- 아이디 + 숫자 4자리로 들어가요 (가벼운 보안 — 진짜 비밀번호는 쓰지 마세요)
- 같은 아이디로 들어가면 캐릭터 1~4번을 가족이 함께 쓰고, 한 캐릭터는 한 기기에서만 열려요
- 온라인 저장·불러오기, 온라인 결혼 신청(결혼 = 해피 엔딩)

## 설정
1. Firebase에서 Realtime Database를 만들고, 규칙(Rules)에 `database.rules.json` 내용을 붙여 넣어요.
2. `config.js`의 `window.TOKDAMA_DB`에 데이터베이스 주소를 넣어요.
3. GitHub Pages(Settings → Pages → main 브랜치)로 공개해요.
